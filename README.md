 # Design Portfolio

 Portfolio personal construido con React, TypeScript, Vite, Motion y Tailwind CSS.

 ## Ejecutar en local

 Instala dependencias:

 ```bash
 npm install
 ```

 Levanta el servidor de desarrollo:

 ```bash
 npm run dev
 ```

 Compila para producción:

 ```bash
 npm run build
 ```
